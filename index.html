Adaptive Feature Selection for Student Performance Prediction

Active

College mini project

A mini project based on the AFSA algorithm from Koushik Roy and Dewan Md. Farid, “An Adaptive Feature Selection Algorithm for Student Performance Prediction,” IEEE Access, 2024.

  • AFSA combines multiple feature-ranking methodologies using a normalized mean ranking.
  • It selects features iteratively, with a threshold that adapts according to feature rank.
  • The paper evaluates AFSA against established feature-selection methods on four datasets and five classifiers.
